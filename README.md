# 🛡️ 宝塔定制化 WAF 插件 (V2Board 专属增强版)

本插件是一款专为 V2Board 机场面板量身定制的 Nginx 底层 WAF（Web 应用防火墙）插件。旨在以极低的资源消耗，防御 GFW 主动探测、空间测绘扫描以及恶意漏洞爆破，同时完美兼容 V2Board 的核心业务逻辑。

## 🌟 核心特性

- **🚀 零性能损耗**：基于 Nginx `access_by_lua_file` 阶段拦截，无需进入 PHP 进程，极速过滤垃圾流量。
- **🛡️ 抗 GFW 探测 (焦油坑 Tarpit)**：对扫描器和非法爬虫不再简单返回 403，而是切入“焦油坑”模式。通过挂起 TCP 连接并缓慢发送无效数据，拖死探测脚本，欺骗 GFW 使其判定网站为死链，极大降低域名被墙概率。
- **✅ 业务级双向免死金牌 (白名单)**：
  - 自动放行 `/api/v1/client/subscribe` 及自定义安全订阅路径，确保客户端拉取订阅永不误杀。
  - 自动放行 `/api/v1/server/`，完美兼容基于 Go 语言（如 Xray/UniProxy）的中转节点与面板的后端通信。
- **👁️ 穿透代理识别**：自动穿透 Cloudflare (CF) 小黄云及前置反代服务器，精准获取访客真实 IP（支持 `CF-Connecting-IP`、`X-Real-IP` 等）。

## 📦 安装指南 (安装至宝塔面板)

### 方法一：极客终端安装（推荐 ⭐⭐⭐⭐⭐）
直接在服务器通过 SSH 克隆本仓库，文件夹名称将自动规范化，以后升级仅需 `git pull`。

```bash
# 1. 进入宝塔插件目录
cd /www/server/panel/plugin/

# 2. 拉取代码并强制命名为 btwaf_v2board
git clone https://github.com/wxfyes/bt_waf.git btwaf_v2board

# 3. 刷新宝塔【软件商店】，即可在已安装列表中看到该插件
```

### 方法二：宝塔后台导入 ZIP 安装
1. 点击本仓库右上角的 **Code** -> **Download ZIP**。
2. **⚠️ 极其重要**：解压下载的压缩包，**进入解压后的文件夹内部**，选中所有文件（包含 `info.json` 等）。
3. 将选中的文件**重新压缩**为一个新的 ZIP 文件（确保 `info.json` 在压缩包的最外层根目录）。
4. 进入宝塔面板 -> 软件商店 -> 点击右上角 **【导入插件】**，上传您刚才重新打包的 ZIP 文件即可。

## 🛠️ 使用说明

1. 安装完成后，在宝塔软件商店点击 **【设置】** 打开插件主界面。
2. 在左侧选择目标站点，点击绿色的 **【一键注入防护】**。
3. 如果您对站点进行了修改（如开启强制 HTTPS、申请 SSL 证书），可能会导致 Nginx 配置文件被宝塔重置。此时请打开插件，重新点击 **【一键注入防护】** 即可恢复。
4. 插件面板自带实时拦截日志功能，可随时查看被拦截的爬虫和恶意探针。

## ⚠️ 配合 Cloudflare 的最佳实践
- 强烈建议主面板域名开启 Cloudflare 小黄云（代理状态），隐藏真实源站 IP。
- 即使开启 CF，本 WAF 依然不可或缺：它能作为底层最后一道防线，拦截伪装极好的高级爬虫以及直接针对源站 IP 泄漏发起的扫描。
