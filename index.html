使用说明书

架构原理

本 WAF 运行在 Nginx Lua 层（应用防火墙），不仅防御 SQL 注入等常规攻击，特有的**“焦油坑反制”**和**“空 UA 斩杀”**专门对抗 GFW 主动嗅探和网络空间测绘扫描器。

第一步：注入站点

在【安全总览】中选择您的域名，点击“一键注入防护”。插件会自动修改 Nginx 的 server 块并生效规则。

第二步：适配框架

如果是 V2Board 机场面板，请在【框架适配】中选择 V2Board，以免误杀节点通信和 Telegram 机器人。

内网诊断工具

如果您不确定防护是否生效，点击【内网穿透诊断】，系统会向您自己发射一枚攻击探针，如果是绿色的 406 或 444 状态码，说明防护固若金汤！
