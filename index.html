插件使用说明

1. 核心防御机制

本插件通过修改 Nginx 配置文件，注入 Lua 拦截脚本。由于运行在 Nginx 层面，性能极高。针对 V2Board/Laravel 等现代框架，建议在“框架适配”中开启专属模式。

2. 双模反控原理

在面对极端 CC 或 DDoS 攻击导致源站带宽打满时，传统的 SSH 或宝塔面板可能无法登录。此时，通过部署 Cloudflare Worker 代理 Telegram Webhook 请求，即使源站失联，您依然可以通过 Telegram 机器人向源站下发封禁、开启全局验证码等指令（通过 CF 边缘网络隐蔽回源）。

3. 目录权限说明

插件会在 /www/server/nginx/conf/waf/ 目录下生成规则文件，请确保 Nginx 进程对该目录具有读权限。
